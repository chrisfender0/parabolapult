# Parabolapult

Finish the parabolic launch equation with the right number and your projectile arcs into the container. Get it wrong and it crashes into the environment.

Built with three.js + Vite. Live at https://chrisfender0.github.io/parabolapult/ (once session 1.1 ships).

## Status

Planning. The build is broken into one-session-at-a-time plans in [`plan/`](plan/) — start with [`plan/00-PLAN.md`](plan/00-PLAN.md).

## Development

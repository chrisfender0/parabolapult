# Session 8.1 — Reset Data

## Goal

A way to wipe saved state from the landing page, same as the memory-card-matching game.

## Depends on

Session 8.

## Tasks

- "Reset Data" button on the landing page, visually secondary (small, muted, bottom of the page).
- Inline confirmation step (button becomes "Are you sure? Yes / Cancel") rather than a `window.confirm` dialog.
- On confirm: `leaderboard.clearAll()` removes every `parabolapult:*` key, then the landing page re-renders into its empty state without a page reload.
- Hide the button entirely when there's nothing stored.

## Files touched

`src/ui/screens/Landing.js`, `src/storage/leaderboard.js`, `src/style.css` (edit).

## Done when

With scores saved, Reset Data → confirm clears the table to the empty state and the button disappears; reloading confirms nothing came back; `localStorage` contains no `parabolapult:` keys.

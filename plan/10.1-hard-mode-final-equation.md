# Session 10.1 — Hard Mode: The Final Equation

## Goal

The payoff: a fourth equation with three color-outlined inputs joined by randomized `+` / `−`, where the player re-enters the three values they memorized. The expression's value is the launch distance.

## Depends on

Session 10.

## Design notes

The final expression is built from the **correct** answers `r1, r2, r3` of the three timed equations, with two randomly chosen operators from `+` and `−` only (never `×` or `÷`), evaluated strictly left to right:

```
r1  op1  r2  op2  r3
```

Constraint: the value must land in the playable range (3–20). Re-roll the operator pair until it does; if no pair works for the drawn `r` values (possible with small numbers), regenerate the third equation before the sequence starts — so **the operator draw and range check happen up front in session 10's generator**, not after the player has memorized anything. The target marker is set to that value.

Each of the three inputs carries the outline color and ①②③ badge of the equation it corresponds to, in order. The operators are shown; the inputs are blank.

The player's launch distance is computed from **what they type**, not from the correct values — a mis-remembered number must visibly fly to the wrong marker.

## Tasks

- Extend `src/game/HardSequence.js` (or add `src/game/HardFinal.js`) with `buildFinal(r1, r2, r3, rng)` → `{ ops: [op1, op2], value, evaluate([a, b, c]) }`, including the up-front range validation described above.
- HUD: final-equation panel with three inline inputs, each with its color outline + badge, the two operators between them, and a Launch button. Tab/Enter moves between inputs; Enter on the last one launches.
- `GameController`: on `hard:sequenceComplete`, set the target to `final.value`, show the final panel, and on submit evaluate the *typed* triple and launch that distance.
- Retries: a miss in hard mode **replays only the final equation** — the three timed equations are not re-shown (the player has already spent their memorization) and the target does not move. Tries indicator behaves as everywhere else.
- Feed `timeLeftTotal` into session 9's speed bonus (up to +60, scaled linearly against the 45s total).
- Round summary on the results screen shows, for hard rounds, each remembered value the player typed next to the correct one in its color — the reveal they were denied during play.

## Done when

A full hard round runs: three timed equations → final colored triple-input equation → launch at the typed value → hit or crash at the right marker. Wrong memorization crashes at exactly the value typed. Retries replay only the final equation. The results screen reveals typed-vs-correct per color. The generated final value is never outside 3–20 across 500 seeded generations.
